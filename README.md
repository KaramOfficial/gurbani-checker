# Gurbani Checker

Per-word Gurbani subtitle alignment checker (Sehaj Paath, Bhagat Jaswant Singh Ji).

- CTC forced alignment (manandey/wav2vec2-large-xlsr-punjabi), 20 ms frames
- Angs 1–550 included; audio streams from media.gursevak.com
- Static page — open `index.html`, no build step

Live: https://karamofficial.github.io/gurbani-checker/
